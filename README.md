# Prompt Press — a working prompt library

Astro (static) + Cloudflare Pages. One source of truth, three outputs:
the site, the per-prompt pages, and the downloadable data files.

**Live workflow:** you send raw data → Muse rewrites it as a clean,
categorised prompt → it's added to `src/data/prompts.json` → build
regenerates the downloads → push to GitHub → Cloudflare redeploys.

## Run it

```bash
npm install
npm run dev        # http://localhost:4321
npm run build      # builds downloads + dist/
npm run preview
```

## Add a prompt

See `data/add-prompt-template.md`. Short version: edit ONLY
`src/data/prompts.json`, then run `npm run data:build`. Never hand-edit
`public/downloads/*` — they are generated by `scripts/build-data.mjs`.

Prompt fields: `id`, `slug`, `title`, `category`, `summary`, `prompt`,
`variables[]`, `tags[]`, `format?`. Categories live in the same file.

## Deploy to Cloudflare Pages

1. Push this repo to GitHub.
2. Cloudflare Dashboard → Pages → Create → Connect to Git →
   select this repo.
3. Build command: `npm run build` · Output directory: `dist`
4. Every push to `main` redeploys automatically.

Or with Wrangler: `npx wrangler pages deploy dist --project-name prompt-press`
(after `npm run build`).

## Design notes — deliberately not generic-AI

No purple/blue gradients, no glassmorphism, no glow, no Inter/Poppins,
no sparkle icons. Paper `#f5f0e4`, ink `#1b1813`, one vermilion accent,
Fraunces serif display, IBM Plex Mono labels, Instrument Sans body.
Cards are index cards with a hard shadow and a rotated category stamp —
a print shop, not a chatbot.
